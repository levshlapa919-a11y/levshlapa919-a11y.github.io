# YZITK Messenger (Узитк мессенджер)

**[YZITK Chats](https://levshlapa919-a11y.github.io/QWEN-8/)** — бесплатный мессенджер в браузере.

## Что умеет
- Личные чаты, группы и каналы
- Голосовые и видеозвонки
- Стикеры и подарки
- Мини-игры: мины, монетка, кости, колесо
- Внутренняя валюта TIX и рынок NFT

## Как открыть
Просто зайди на сайт: [yzitk messenger](https://levshlapa919-a11y.github.io/QWEN-8/).
На Android — «Установить приложение» через меню браузера, на iPhone — «На экран Домой» через Safari.
